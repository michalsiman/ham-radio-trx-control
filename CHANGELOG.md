# Changelog

## [Unreleased]

## [0.2.0] - 2026-11-11

- Frequency display in a frame like a radio's LCD, in MHz to 100 Hz (14.0745), with a mark under each digit to choose the tuning step.
- Tuning knob with a finger dimple: drag around it, scroll over it or use the arrow keys; the frequency is sent when it stops. ⌨ in the display opens a field to type a frequency.
- Band buttons (80, 40, 20, 15, 12, 10 m by default): tune to the band's last used frequency, remembered per browser, else to a default for the mode. Mode and band buttons each fit one row.
- S-meter: only the lit part is drawn, so a weak signal no longer looks strong on themes with a transparent divider colour.

## [0.1.0] - 2026-11-11

- First version: frequency with band, mode buttons, TX power slider, S-meter, on/off and TX state; tune by tapping the frequency. English and Czech.
